Start tracking your NSE dividend income

Add the stocks you own. The tracker fetches each company's dividend history and lets you record how many shares you held each quarter.

  1. 1
    Add a ticker

    Type one or more NSE symbols in the box above — for example RELIANCE, TCS or HDFCBANK. Set the default quarterly quantity (you can edit every quarter later) and press ＋ Add.

  2. 2
    Dividend data comes from stockanalysis.com

    Prices, yields and payout history are fetched live and cached for 6 hours. If the source is unreachable, your saved quantities are never touched.

  3. 3
    Everything stays on this computer

    Holdings are stored in a local ChromaDB database with a JSON backup mirror. There is no account, no cloud sync and no analytics. Only dividend lookups leave this machine.
